git diff - показывает различия между состояниями файлов, можно сравнивать рабочую папку, индексы, коммиты

git show - показывает содержимое конкретного коммита конкретно дату, автора, сообщение и изменения

git log - показывает историю коммитовв 



команда git log -S"def" --oneline -- lab03/calc.py ищет коммиты, в которых изменилось количество вхождений строки def в файле


оманда git blame lab03/calc.py показывает, каким коммитом и автором была добавлена или изменена каждая строка файла

в ходе работы я создал несколько версий калькулятора, сохранил их отдельными коммитами и научился сравнивать изменения, просматривать историю и определять происхождение строк кода
